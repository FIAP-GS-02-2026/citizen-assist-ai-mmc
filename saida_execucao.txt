(c) Forma matricial A·x = b:
A =
  [  1   1   1   1 ]

  [  0   1   2   0 ]
  [  1   0   1   2 ]
x = [N, S, L, O]^T
b = [72, 76, 52, 76]^T

(d) Existência e unicidade da solução:
    det(A) = 3  (cálculo exato)   | numpy: 3.0000
    posto(A) = 4, posto([A|b]) = 4, nº de incógnitas = 4
    Pelo Teorema de Rouché-Capelli: posto(A) = posto([A|b]) = 4 = nº de incógnitas,
    então o sistema é possível e determinado (SPD): existe UMA única distribuição.
    Equivalente: det(A) != 0, logo A é invertível e x = A^-1 · b.

(d)/(e) Transformação linear T: R^4 -> R^4, T(x) = M·x, com
M =
  [     1      0      0   1/12 ]

  [     0   1/20      1   1/24 ]
  [     0      0      0    7/8 ]

    diagonal = fração que permanece na própria região.

    [ 1.0000  0.0000  0.0000  0.0833 ]
    [ 0.0000  0.9500  0.0000  0.0000 ]
    [ 0.0000  0.0500  1.0000  0.0417 ]
    [ 0.0000  0.0000  0.0000  0.8750 ]

(f) Propriedades:
    Soma de cada coluna de M: ['1', '1', '1', '1']  =>  1^T·M = 1^T
    Logo, para qualquer x: soma(T(x)) = 1^T·(M·x) = (1^T·M)·x = 1^T·x = soma(x).
    Todos os coeficientes M[i][j] >= 0: True
    Logo, para qualquer x >= 0: T(x)_i = soma_j M[i][j]·x_j >= 0 (soma de termos >= 0).
    det(M) = 133/160 != 0 -> T é invertível (a política pode ser desfeita).
